# О чем проект? 
Веб-сервис для ведения личных и общих списков покупок: семья, пары, сожители, группы(праздники, ремонт, поездки). Список видят и отмечают несколько человек

# Цель и идея
Обычные заметки и мессенджеры теряют контекст: нет сроков, категория, статусов. Мы создаем единое пространство для личных и совместных закупок, чтобы сократить спонтанные и повторные покупки и время согласование бытовых вопросов

# Функции первой версии
1. Регистрация и вход
2. Создание списка покупок
3. Добавление товаров в список
4. Отметка товара как "куплено"
5. Удаление товаров и списков
6. Приглашение человека в список по ссылке
7. Страница "Мои списки": свои списки и те, куда пригласили
